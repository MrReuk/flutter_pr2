# Материалы для отчёта по практической работе 2

## Ошибка в deleteMany

Исходный код:

```dart
final i = _books.indexWhere((b) => b.id == id && !b[i].isDeleted);
```

Внутри замыкания, которое ещё вычисляет `i`, используется сама переменная `i`, а к элементу `b` типа `Book` применяется оператор индексации `b[i]`. У `Book` нет оператора `[]`, а `i` в этот момент ещё не объявлена, поэтому код не компилируется.

Исправление: проверять флаг самого элемента, а не обращаться по индексу.

```dart
final i = _books.indexWhere((b) => b.id == id && !b.isDeleted);
```

Условие `!b.isDeleted` нужно, чтобы уже удалённая запись не удалялась повторно и не попадала в счётчик. Это проверено тестом «Множественное удаление считает только действительно удалённые записи».

## Схема слоёв

```
screens  ──►  widgets  (EntityTable, PaginationBar, ListToolbar)
   │
   ▼
state    (PagedListNotifier, DetailNotifier, ReferenceNotifier)
   │
   ▼
repositories  (интерфейс  ◄──  InMemoryBookRepository, InMemoryAuthorRepository)
   │
   ▼
models + data  (Book, Author, PageResult, BookQuery, AuthorQuery, начальные наборы)
```

Экраны и виджеты получают данные только из `state`. `state` вызывает интерфейсы репозиториев и не знает, где лежат данные. В ПР4 заменяется только реализация репозитория, экраны остаются прежними. Состояние списка определяется адресом: экран читает параметры из `go_router`, превращает их в `BookQuery` и передаёт в `BookListNotifier`.

## Почему таблица вынесена в обобщённый виджет

В приложении будет шесть-восемь списков: книги, авторы, жанры, издательства, читатели, выдачи. Отдельный экран для каждого дал бы почти одинаковые файлы со своей таблицей, сортировкой, выделением, пагинацией и обработкой четырёх состояний, и любая правка делалась бы везде.

`EntityTable<T>` принимает описание колонок `TableColumnSpec<T>`, список элементов и функции `idOf`, `onSort`, `actions`. Всё остальное одинаково: прокрутка, флажки, стрелка сортировки, зачёркивание удалённых строк. Вокруг неё `EntityListBody<T>` добавляет состояния загрузки, ошибки и пустого результата, переключение на карточки и пагинацию. Экраны книг и авторов отличаются только колонками, фильтрами и названиями полей, а новый список добавляется описанием колонок, без копирования кода.
