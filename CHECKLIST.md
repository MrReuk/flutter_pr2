## Ручная проверка
| Что сделать | Ожидаемо |
|---|---|
| Открыть `/books` | таблица, 10 строк, «Страница 1 из 3», «Всего записей: 26» |
| Щёлкнуть заголовок «Год» дважды | стрелка вверх, затем вниз, адрес `sort=year,desc` |
| Ввести «папа» | через 300 мс в адресе `search=папа`, две строки |
| Открыть адрес с параметрами в новой вкладке | то же состояние списка |
| Кнопка «назад» браузера | предыдущий набор условий, поля ввода обновились |
| Поиск `zzz` | пустой результат с кнопкой «Сбросить условия» |
| Поиск `!error` | красный экран ошибки с кнопкой «Повторить» |
| Отметить несколько строк, «Удалить выбранные» | подтверждение, затем счётчик и снекбар |
| «Показывать удалённые» | удалённые строки зачёркнуты, есть «Восстановить» |
| Сузить окно до 400 px | карточки вместо таблицы, выбор сортировки сверху |
